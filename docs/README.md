按**用途**分类，不按时间。每份文档头部都有统一的状态声明。

状态词只有四个：**已实现**（代码已落地并跑通）｜**定案**（协议已确认，未或部分实现）｜**设计稿**（方案已写，未实现）｜**报告**（一次性快照）。

## 新增文档时

1. 按用途放进对应子目录（`协议/` `模块/` `设计/` `参考/`）
2. 标题后紧跟一行：`> **状态**：已实现 ｜ **日期**：2026-10-18`
3. 在本索引对应表格补一行

不要再用「研究」「笔记」「定案/接入/打通」之类的词进标题——状态归状态行，标题只写这是什么。一次性快照不纳入公开仓。
